# Round 2: defects and real execution

Approved specification: second-round task brief and docs/05_DEVICE_AGENT.md. Execute inline, in order, with regression tests before fixes and one independent final review.

1. B1–B5: restrict retransmission to dispatched; cursor-filter outbox; commit valid event prefixes and compact inbox payloads; queryer-based transactions and recorded receipts; queued pending_reason. Each gets a failing regression, then full Phase 1 suite must pass before Phase 2 code.
2. Workspaces: explicit logical-root mapping and program allowlist; canonical path confinement including existing-parent symlinks; clean matching Git HEAD preflight before starting user commands. Patch/input artifacts stay explicitly unsupported.
3. Local capabilities: process.exec/cancel, filesystem.read/write, git.inspect with typed input schemas and structured results. Durable log byte offsets and outbox entries are one transaction.
4. Process ownership: detached same-binary runner holds Linux process group/Windows Job and writes identity/start/exit files; Agent stores PID/creation/boot/log identity and can resume tail after restart. KILL_ON_JOB_CLOSE belongs to the runner, not the transient Agent.
5. Real Git/TLS E2Es: parallel command+Git summary, mismatch prevents execution, cancellation kills descendants within 2 seconds, filesystem confinement. Include failed commands, timeout, program allowlist, logging >100 events and restart/PID reuse regressions.
6. Regenerate schema, all modules test+vet, race checks, nine CGO-free cross-builds, demo, independent review, report and PR. Native Windows runtime is only claimed if actually exercised.

Implementation decisions: default termination grace 500ms (task brief overrides the old 5-second design default); process.exec requires an allowed executable name, but the allowlist is not a kernel isolation boundary for interpreted commands. Working directories are authorized roots; Git-context tasks use isolated clean worktrees so commands do not race with original workspace edits. Artifact/patch references fail explicitly until their transfer implementation exists.
