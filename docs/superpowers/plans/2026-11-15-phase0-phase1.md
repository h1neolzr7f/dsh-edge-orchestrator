# Phase 0/1 Runtime Implementation Plan

> For agentic workers: execute inline with superpowers:executing-plans, followed by one independent whole-branch review.

**Goal:** Run a persistent Coordinator and two real networked Workers; advance a three-task DAG with Controller offline, deduplicate tasks and restore all events through one cursor.

**Architecture:** Go Workspace modules share protocol types. Coordinator owns SQLite, ordered event ingestion, DAG gates and dispatch. Workers own SQLite receipts/execution records/outbox and reconnect through Edge Link. HTTP JSON exposes controller actions; TLS WebSockets carry worker control frames and receipt/events. SQLite is pure Go.

**Tech Stack:** Go >=1.22, modernc.org/sqlite, coder/websocket, Masterminds/semver.

**Spec:** docs/04_PROTOCOL_CONTRACT.md, docs/07_VALIDATION.md sections 7.9–7.10, and approved Phase 2 task brief.

## Global Constraints

- go.work includes apps/coordinator, apps/edge-agent, apps/edge-cli, packages/protocol, packages/edge-link; add packages/orchestrator and root test module.
- CGO_ENABLED=0 supports Windows amd64, Linux amd64, Linux arm64.
- Runtime plan dependencies belong to Coordinator, never Controller.
- sequence/ack reset per socket; worker_seq is persistent per device; coord_seq is global.
- No automatic re-execution of an accepted task after restart; reconcile persistent receipt and execution state.
- Phase 0/1 uses device.inspect and deterministic report aggregation, not arbitrary process execution. Process groups, Job Objects, worktree preparation and full chunked artifacts remain later-phase features and cannot be advertised as implemented.
- Development enrollment uses explicit controller and per-device worker bearer tokens over TLS; QR/keypair pairing and Flutter/Cordis integrations are later phases.

## Review Focus

- Reconnect after receipt loss must not run an accepted task twice.
- Coordinator restart must recover dependency gates and pending dispatch from SQLite.
- Out-of-order or duplicate worker events must not invert task state or unlock twice.
- Invalid DAG, idempotency collision and capability mismatch must leave no partial plan.
- A snapshot or paginated replay must not skip concurrent events or advance a global cursor from a single card.
